# PowerBI-Blinkit-Sales-Analysis
Built an interactive Power BI dashboard to analyze Blinkit grocery sales data. Designed KPI cards for Total Sales, Average Sales, Item Count, and Customer Ratings. Created visualizations including bar charts, donut charts, line charts, and outlet performance analysis. Implemented interactive slicers and filters for dynamic business insights.

Project Overview

Developed an interactive Power BI dashboard to analyze Blinkit grocery sales data. The dashboard provides insights into sales performance, item categories, outlet characteristics, and customer ratings.
